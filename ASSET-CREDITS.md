# Pitfall canyon assets

- Kenney Nature Kit 2.1 — https://kenney.nl/assets/nature-kit — CC0. Actual OBJ meshes used for cliff-foot rocks, rock towers, cacti, bushes, and grasses; sandstone materials recolored for this scene.
- Kenney Survival Kit 2.0 — https://kenney.nl/assets/survival-kit — CC0. Actual meshes used for workbenches, anvil, barrels, crates, chest, bedroll, pickaxe, bottle, loose wood and stones, logs and planks. Original palette preserved.
- Original licenses are retained in assets/nature/License.txt and assets/survival/License.txt.
- Three.js 0.160.1 — MIT; license retained in THREE-LICENSE.txt. Bundled locally so file opening needs no CDN or server.
- Canyon terrain, cabin structure, solar panels, flags, mine tunnel, timber supports, rails, mine cart and lighting are custom scene geometry. PEAK is a visual reference only; no PEAK assets are copied.

To rebuild the offline model bundle after changing source OBJ files: node tools/pack-assets.cjs.
