# Pitfall

First-person canyon exploration game. Keyboard and mouse required.

Enable GitHub Pages with Settings > Pages > Source: GitHub Actions. Push this folder to the repository default branch; the Pages workflow publishes it automatically.

Open index.html locally or serve this folder with any static HTTP server. Browser saves belong to each device and site address; local file saves do not transfer to the published site.

See ASSET-CREDITS.md and bundled license files for third-party assets.
